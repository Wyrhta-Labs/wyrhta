# Repo Skills

Skills in this directory are the canonical repo-owned copies. Runtime-specific
stub skills may exist under `.codex/skills`, `.claude/skills`, and
`.opencode/skills`; those stubs should only carry frontmatter plus a pointer
back here.

- `wyrhta-demo`: run, seed, reset, and verify the throwaway Wyrhta demo household.
- `wyrhta-dev-env`: start, inspect, and troubleshoot the local dev stack.
